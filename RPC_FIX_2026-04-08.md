# RPC GPU Offload Fixes - 2026-04-08

**Issue**: RPC Server starts and client connects, but only CPU is loaded from the client. Client's own GPUs are not used and Server's GPUs are also not used.

## Root Causes Identified

### 1. Device Override Overwrite (gpttype_adapter.cpp)
When RPC devices were added to `devices_override`, they were later **overwritten** when `inputs.devices_override` was processed. This caused RPC devices to be lost.

**Fix**: 
- Keep RPC devices in `devices_override` and append local devices instead of replacing
- Use a separate `rpc_devices` vector to avoid mixing with local device overrides
- Only apply `model_params.devices` once after all devices are collected

### 2. Incorrect RPC Device Detection (gpttype_adapter.cpp)
The code was checking the **buffer type name** for "RPC" instead of the **backend registry name**. This could miss RPC devices.

**Fix**:
- Use `ggml_backend_dev_backend_reg(dev)` to get the registry
- Check `ggml_backend_reg_name(reg)` for "RPC" (matching llama.cpp's approach)
- Add debug output showing registry name for troubleshooting

### 3. RPC Auto-Offload Not Triggering (koboldcpp.py)
The auto-offload for RPC only triggered when `args.gpulayers == 0`, but the default value is `-1`. This meant RPC users without explicit `--gpulayers 0` would not get full offload.

**Fix**:
- Trigger auto-offload when `args.gpulayers == 0 OR args.gpulayers == -1`
- This ensures RPC users get full offload by default

## Changes Made

### File: gpttype_adapter.cpp

```cpp
// Handle RPC endpoints - connect to RPC server(s) FIRST
std::string rpc_endpoints_str = inputs.rpc_endpoints;
bool use_rpc = false;
if(rpc_endpoints_str != "" && rpc_endpoints_str.length() > 0)
{
    printf("[RPC] Connecting to RPC server(s): %s\n", rpc_endpoints_str.c_str());
    // Parse comma-separated endpoints and add each one
    size_t start = 0;
    size_t end = rpc_endpoints_str.find(',');
    while (end != std::string::npos) {
        std::string endpoint = rpc_endpoints_str.substr(start, end - start);
        printf("[RPC] Adding RPC server: %s\n", endpoint.c_str());
        ggml_backend_rpc_add_server(endpoint.c_str());
        start = end + 1;
        end = rpc_endpoints_str.find(',', start);
    }
    // Add last endpoint
    std::string endpoint = rpc_endpoints_str.substr(start);
    printf("[RPC] Adding RPC server: %s\n", endpoint.c_str());
    ggml_backend_rpc_add_server(endpoint.c_str());
    
    // Get RPC devices that were added and add them to override list
    printf("[RPC] Enumerating RPC devices...\n");
    std::vector<ggml_backend_dev_t> rpc_devices;
    for (size_t i = 0; i < ggml_backend_dev_count(); ++i) {
        auto* dev = ggml_backend_dev_get(i);
        ggml_backend_reg_t reg = ggml_backend_dev_backend_reg(dev);
        std::string reg_name = reg ? ggml_backend_reg_name(reg) : "";
        if(reg_name.find("RPC") != std::string::npos) {
            printf("[RPC] Found RPC device %zu: %s (registry: %s)\n", i, ggml_backend_dev_name(dev), reg_name.c_str());
            rpc_devices.push_back(dev);
        }
    }
    if(rpc_devices.size() > 0) {
        printf("[RPC] Using %zu RPC device(s) for offloading\n", rpc_devices.size());
        // Add RPC devices to the beginning of devices_override
        devices_override.insert(devices_override.begin(), rpc_devices.begin(), rpc_devices.end());
        use_rpc = true;
    } else {
        printf("[RPC] WARNING: No RPC devices found after connecting to server\n");
    }
}

std::string dev_override_str = inputs.devices_override;
if(dev_override_str!="")
{
    auto local_devices = kcpp_parse_device_list(dev_override_str);
    if(local_devices.size()>0)
    {
        printf("\nOverriding with %zu devices...\n",local_devices.size()-1);
        // If using RPC, keep RPC devices at the front and add local devices after
        if(use_rpc && devices_override.size() > 0) {
            // Add local devices after RPC devices
            devices_override.insert(devices_override.end(), local_devices.begin(), local_devices.end());
        } else {
            devices_override = local_devices;
        }
    }
}

// Apply device overrides if we have any devices
if(devices_override.size() > 0) {
    model_params.devices = devices_override.data();
    // Force GPU usage by setting n_gpu_layers to max when using RPC or custom devices
    if(use_rpc) {
        model_params.n_gpu_layers = 999;
    }
}
```

**Note**: `--gpulayers 999` is now optional (auto-detected), but recommended for explicit control.

## Verification Steps

1. **Check RPC devices are enumerated**:
   - Look for "[RPC] Found RPC device" in client output
   - Verify device count matches server configuration

2. **Check model offloading**:
   - Look for "offloading X layers to GPU" in client output
   - Verify layer count is > 0 (ideally 999 for full offload)

3. **Check server GPU usage**:
   - Monitor Vulkan GPU memory on server
   - Should see memory allocation during model load
   - Server logs should show "Processing graph compute request"

4. **Check client GPU usage** (if using hybrid mode):
   - If client has local GPUs and uses `--device` with `--rpc`
   - Both client and server GPUs should be utilized
   - RPC devices listed first, then local devices

## Known Limitations

- RPC requires server to start **before** client
- RPC performance depends on network latency/bandwidth
- Very large models may experience slower loading over RPC
