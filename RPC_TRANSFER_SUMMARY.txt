USAGE EXAMPLES
================================================================================

Start RPC Server (remote host with GPU):
  $ bin/rpc-server -d CUDA0 -p 50052

Connect from Client:
  $ koboldcpp --model model.gguf --rpc 192.168.1.100:50052

Multiple Servers:
  $ koboldcpp --model model.gguf --rpc 192.168.1.100:50052,192.168.1.101:50052

With Caching:
  $ bin/rpc-server -c -p 50052

Debug Mode:
  $ GGML_RPC_DEBUG=1 bin/rpc-server

================================================================================
OPTIMIZATION FEATURES
================================================================================

1. Tensor Hashing (threshold: 10 MB)
   - Computes FNV-1a hash for large tensors
   - Skips transfer if server has cached version
   - Reduces model loading time

2. Graph Caching
   - First execution: GRAPH_COMPUTE
   - Subsequent: GRAPH_RECOMPUTE
   - Avoids serialization overhead

3. RDMA Transport (Linux only)
   - Auto-negotiated when available
   - Lower latency than TCP
   - Requires libibverbs
